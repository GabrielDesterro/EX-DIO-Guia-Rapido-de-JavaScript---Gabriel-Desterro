# Guia Rápido de JavaScript
 ***
Quer aprender JavaScript do zero?

Esse ebook é o seu atalho para dominar as bases da linguagem mais usada na web!

## O que você vai encontrar por aqui:

**Sintaxe simples e direta**: Variáveis, funções, condicionais, loops e muito mais explicados de forma clara e objetiva.
**Exemplos práticos**: Códigos que você pode copiar e colar para testar na hora.
**Conceitos avançados**: Domine o DOM e até mesmo Promises e Async/Await para criar aplicações dinâmicas.
**Linguagem fácil**: O texto é escrito de forma clara e divertida, sem enrolação.

## Por que você precisa desse ebook?

Começar do zero: Perfeito para iniciantes que querem dar os primeiros passos em programação.
Revisão rápida: Ideal para quem já tem alguma experiência e precisa revisar os conceitos básicos.
Referência rápida: Mantenha esse guia por perto como um dicionário de JavaScript.

**Assuntos abordados**:

- Variáveis e tipos de dados
- Funções e suas diferentes formas
- Condicionais e loops
- Objetos e arrays
- Manipulação do DOM
- Promises e Async/Await
